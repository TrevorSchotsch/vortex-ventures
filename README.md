# Vortex Ventures 🌌

**Vortex Ventures** is a fictional travel agency offering adventures beyond time, space, and reality. This front-end project showcases UI design, JavaScript interactivity, and a localStorage-based login system — wrapped in a creative sci-fi/fantasy theme.

🔗 **Live Site:** [https://vortex-ventures.netlify.app](https://vortex-ventures.netlify.app)

---

## Features

-  Image carousel with custom navigation
-  Login/Signup system using localStorage
-  Auth-based navbar + dropdown menu
-  Modal image previews
-  Clean layout and thematic styling

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)
- Netlify (for deployment)
- LocalStorage (for user session handling)
